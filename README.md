# Pyrite.jl
[![Run tests](https://github.com/toma-vlad/Pyrite.jl/actions/workflows/CI.yml/badge.svg)](https://github.com/toma-vlad/Pyrite.jl/actions/workflows/CI.yml)
[![Aqua QA](https://juliatesting.github.io/Aqua.jl/dev/assets/badge.svg)](https://github.com/JuliaTesting/Aqua.jl)

Pyrite.jl is a Julia package for the simulation of laser–matter interaction in industrial processes with a focus on metals, built on top of [Ferrite.jl](https://ferrite-fem.github.io/Ferrite.jl/stable/) and [DifferentialEquations.jl](https://docs.sciml.ai/DiffEqDocs/stable/).

## Status

The package is in early development.
